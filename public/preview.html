Flujo de uso

Un popup sencillo: abrir, analizar, revisar y exportar.

01

Abre una web

Navega a cualquier página que quieras resumir, analizar o preparar como contexto.

02

Analiza

La extensión llama a /analyze?url=... usando el servicio configurado.

03

Compara

Visualiza la reducción de tokens entre el HTML original y el Markdown resultante.

04

Exporta

Copia el Markdown al portapapeles o descárgalo directamente como archivo .md.

Permisos usados

Solo los permisos necesarios para consultar la pestaña activa y ejecutar el análisis.

Permiso Motivo
activeTab Permite trabajar sobre la pestaña actual cuando el usuario pulsa el botón de la extensión.
tabs Consulta la URL activa mediante chrome.tabs.query.
fetch Llama al servidor msarknet-convert-html-to-markdown para ejecutar el análisis.
